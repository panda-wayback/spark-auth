# 管理后台

## 目标

个人使用的极简网页后台：创建软件，点进软件就能管理它的私钥批次与已激活设备。

## 要实现的

页面只有六个：

```text
登录 → 软件列表 → 软件的卡密页 → 激活详情
                ↘ 私钥批次列表
     ↘ MCP 接入
```

- 软件列表（登录后首页）
  - 每行：名称、标识、换设备策略、已激活数量、状态。
  - 新建软件；编辑软件（名称、换设备策略、禁用）。
  - 点击软件进入它的卡密页。
- 软件的卡密页
  - 批量签发卡密：填数量与有效天数（单个填 1），生成后同时创建新的私钥批次并列出本批卡密便于复制。
  - 导出 CSV：导出某一批次或全部已签发卡密。
  - 搜索已激活记录（按卡密或设备）。
  - 列表：已激活记录，含卡密、状态、有效时长、到期时间、当前设备、换设备次数；每行可禁用或取消禁用该激活。
- 私钥批次列表
  - 按 product 列出所有私钥批次：批次标识、生成时间、生成数量、有效时长、状态。
  - 可禁用某一批次；禁用后该批次卡密不能用于新激活，已激活设备不受影响。
- 激活详情：当前绑定设备与全部换设备记录，只读。
- MCP 接入：展示可直接复制的 MCP 配置，其中的地址为当前访问后台所用的域名或 IP；提供复制按钮。
- 顶栏只有：MCP 接入、修改密码、退出。

## 关键约束

- 只有一个管理员账号，由命令行创建；后台不提供用户、组等管理页面。
- 不使用 Django 自带后台。
- 未登录访问任何页面都跳转登录页。
- 登录状态 12 小时有效；连续 5 次登录失败，暂停登录 15 分钟；密码只保存哈希值。
- 激活记录与换设备记录只读，不能修改或删除。
- 软件只能禁用，不能删除；软件标识创建后不能修改。
- 私钥批次只能禁用，不能删除；禁用后仅阻止该批次的新激活。
- 已激活记录可禁用，禁用后该设备校验失败；可取消禁用恢复。
- 服务部署在反向代理（nginx / caddy）后时，页面展示的地址使用代理转发的域名与协议。
- 业务规则见 [卡密管理](../key-management/README.md) 与 [设备绑定](../device-binding/README.md)。

## 失败场景

- 账号或密码错误。
- 连续失败达到上限，登录被暂停。
- 登录状态过期，需重新登录。
- 批量签发失败时，页面显示原因。

## 解决步骤

1. 登录、退出、修改密码页面，接入登录失败次数限制。
2. 软件列表页与新建 / 编辑软件表单。
3. 软件的卡密页：批量签发、导出、搜索已激活记录、禁用 / 取消禁用激活。
4. 私钥批次列表页。
5. 激活详情页。
6. MCP 接入页。
