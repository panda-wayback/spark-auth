# 管理后台

## 目标

个人使用的极简网页后台：创建软件，点进软件就能管理它的 key。

## 要实现的

页面只有四个：

```text
登录 → 软件列表 → 软件的 key 页 → key 详情
```

- 软件列表（登录后首页）
  - 每行：名称、标识、换设备策略、key 数量、状态。
  - 新建软件；编辑软件（名称、换设备策略、禁用）。
  - 点击软件进入它的 key 页。
- 软件的 key 页（所有操作只作用于当前软件）
  - 生成 key：填数量与有效天数（单个填 1），生成后列出本批 key 便于复制。
  - 导入 CSV：选文件并填有效天数；有重复时列出重复的 key。
  - 导出 CSV。
  - 按 key 搜索。
  - 列表：key、状态、有效时长、到期时间、当前设备、换设备次数；每行可禁用或取消禁用。
- key 详情：当前绑定设备与全部换设备记录，只读。
- 顶栏只有：修改密码、退出。

## 关键约束

- 只有一个管理员账号，由命令行创建；后台不提供用户、组等管理页面。
- 不使用 Django 自带后台。
- 未登录访问任何页面都跳转登录页。
- 登录状态 12 小时有效；连续 5 次登录失败，暂停登录 15 分钟；密码只保存哈希值。
- 激活记录与换设备记录只读，不能修改或删除。
- 软件与 key 只能禁用，不能删除；软件标识创建后不能修改。
- 业务规则见 [key 管理](../key-management/README.md) 与 [设备绑定](../device-binding/README.md)。

## 失败场景

- 账号或密码错误。
- 连续失败达到上限，登录被暂停。
- 登录状态过期，需重新登录。
- 生成或导入失败时，页面显示原因；导入重复时列出重复的 key。

## 解决步骤

1. 登录、退出、修改密码页面，接入登录失败次数限制。
2. 软件列表页与新建 / 编辑软件表单。
3. 软件的 key 页：生成、导入、导出、搜索、禁用 / 取消禁用。
4. key 详情页。
