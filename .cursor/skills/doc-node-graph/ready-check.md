# Doc Node Graph — Ready Check

进入实现前须检查当前 docs 节点是否足够。

## 检查项

1. `目标` / `要实现的` 可读；关键约束与失败已写清。
2. `解决步骤` 能看出做得到，或已改需求。
3. 所需链接页存在，或空架子契约已有。
4. 对所需能力只读 `目标` + `要实现的`，判定契约可满足；禁止改其解决步骤（待拆除外）。若该能力已有模块 `spec.yaml`，以 `spec.yaml` 为准。
5. 若节点已展开伪软件，各模块 `spec.yaml` + `AI.md` 须已生成并登记到父级 `modules`；`check_index.py` 通过。

## 失败处理

- 任意一项失败 → 先给判断，裁定后再补 docs。
- 禁止未裁定直接进入实现。
